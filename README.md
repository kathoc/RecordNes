# RecordNes

プレイ記録と再生に特化した NES エミュレーターです。巻き戻しやスローモーションを使って
何度でもやり直しながら記録し、**一度も詰まらずに通した一本のプレイ**として mp4 に書き出せます。

スーパープレイ動画やノーコンティニュークリアの記録を作るための道具です。

---

## できること

**記録は勝手に始まります。** ROM を読み込んだ瞬間から、すべての操作が背景で記録されています。
押し忘れという事故が起きません。保存だけは自分で行います。

**巻き戻した跡は残りません。** 失敗したら戻って、やり直してください。捨てた区間はファイルに
入らないので、再生すると最初から完璧に通したように見えます。何度やり直しても同じです。

**難所はゆっくり刻めます。** 1/16 速でもコマ送りでもかまいません。記録に残るのはフレーム単位の
入力だけなので、再生も書き出しも常に実速度になります。

**続きは後日でかまいません。** 途中で保存し、別の日に開いて同じ場所から記録を続けられます。

**動画は録画ではありません。** 書き出しは、記録を最初から走らせ直して作ります。
だからフレーム落ちも描画の乱れも入りません。

## 動作環境

当面は **Linux** 向けに配布します。Windows / macOS のビルド設定は入れてあり、
Android は同じ画面を包む形で対応する予定です（`docs/roadmap.md`）。

ROM は付属しません。手持ちの `.nes` ファイルを使ってください。

## 使い方

### 1. ROM を開く

「ROM を開く」を押すか、ウィンドウへ `.nes` ファイルを落とします。この瞬間から記録が始まります。

### 2. 遊ぶ

| キー | |
|---|---|
| 方向キー | 十字キー |
| Z / X | B / A |
| A / S | B 連射 / A 連射 |
| Enter / 右Shift | START / SELECT |

コントローラーも使えます。**L を押しながら**他のボタンを押すと、巻き戻しやコマ送りなどの
機能が出ます。L 単独では何も起きないので、遊んでいる最中に誤爆しません。

| L + | |
|---|---|
| ← / → | 巻き戻し / 早送り |
| ↑ / ↓ | 速度を上げる / 下げる |
| A / B | コマ送り / 一時停止 |
| X / Y | ステートセーブ / ロード |
| START / SELECT | リセット / 記録を保存 |
| R | 目印を打つ |

X と Y は、通常時は **A と B の連射**です。

### 3. 失敗したら巻き戻す

Backspace を押している間（コントローラーなら L + ←）、時間が戻ります。離すと再生に切り替わります。
そこで**ボタンを押した瞬間**に記録を引き継ぎ、タイムラインがその地点でつながります。

戻っただけでは記録は縮みません。元の続きをそのまま見て、どこで失敗したかを確かめてから
やり直す、という使い方ができます。

### 4. 難所はゆっくり

速度を 1/2 〜 1/16 に落とすか、F キーでコマ送りします。記録は変わりません。

### 5. 保存する

「記録を保存」で `.rnes` ファイルになります。1 時間のプレイでも 1MB 前後です。
ROM は含みません（照合用の SHA-1 だけを持ちます）。

### 6. 動画にする

「動画を書き出す」から mp4 を作ります。範囲、大きさ（1x〜4x）、フレームレート、画質を選べます。

## 連射

スイッチは 3 状態を巡ります。

- **OFF** — 連射しません
- **ホールド** — 押している間だけ連射。押した瞬間は単発で入り、0.5 秒後から連射に移ります
- **トグル** — 一度押すと離しても連射が続きます。撃ちっぱなしにしたい場面向け

速度は 5〜30Hz。連射で作られた入力もフレーム単位で記録されるので、再生は完全に一致します。

## 4-way / 8-way

斜め入力が邪魔になるゲームのために、十字キーを 4 方向へ丸めるモードがあります。
ROM ごとに覚えます。

## 遅延について

押してから画面が変わるまでを短くするために、次のことをしています。

- 入力を読むのは**エミュレートの直前ただ 1 か所**。イベントを受けた時点では確定させません
- **ラン・アヘッド**で、ゲーム自身が持つ反応の遅れを打ち消します
- 音声は 3 フレーム分しか溜めず、溜まり具合に応じて読み出し速度を ±0.5% 曲げて調整します

開発機での実測は `docs/spec.md` の 10.6 にあります。ラン・アヘッドを 3 段入れても
1 フレームあたり 12.9ms で、予算の 16.64ms に収まります。

## 開発

```sh
npm install
npm run dev        # ブラウザで開発 (http://localhost:5173)
npm run electron   # デスクトップアプリとして起動
npm test           # 自動テスト
npm run selftest   # 実アプリを自動操作して確かめる
npm run perftest   # 遅延と計算時間を測る
npm run dist:linux # 配布物を作る
```

`npm test` は ROM を必要とするテストを含みます。ROM が無い環境では自動的に飛ばします。

設計と、調べて分かったことは `docs/spec.md` にまとめてあります。
